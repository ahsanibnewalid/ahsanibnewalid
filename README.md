## 🧭 How I approach development

1. **Understand the problem** — define the user, use case, and constraints.
2. **Design for maintainability** — keep setup and architecture understandable.
3. **Build in small steps** — implement, test, review, and improve.
4. **Document the work** — help the next developer install, run, and contribute.
5. **Keep security in mind** — treat authentication, permissions, secrets, and user data carefully.
